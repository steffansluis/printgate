# Requests for comments

An RFC argues for a change before the code exists: a new kind of check, a change to the
contract or the profile, a new port, or a change to how the project works. Bug fixes and
changes inside one module go straight to a pull request.

The pull request contains only `NNNN-a-short-title.md`, and the discussion happens there.
Statuses: Draft, Discussion, then Accepted, Declined or Withdrawn. Every RFC is merged whatever
its outcome, so the argument stays on record. An accepted RFC's decision is recorded as an ADR;
the ADR holds the decision, the RFC the argument. Use `template.md`.
