# Architecture decision records

One file per decision that later changes must keep to: `NNNN-a-title-in-the-imperative.md`,
written in the same change as the decision or before it. A decision local to one change goes in
its commit message instead.

An accepted ADR is not edited. Overturning one takes a new ADR, and the old one's status
becomes `Superseded by NNNN`. Use `template.md`.
